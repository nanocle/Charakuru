# 制作で使うブラウザの選択と再利用

Tripoやアバターキットを開くときは、ユーザーが使っているデスクトップのブラウザ・ウィンドウ・プロファイルを再利用します。ブラウザ操作ツールの手順を読み、次の順で対象を決めてください。

1. ユーザーが指定したブラウザやタブがあれば、それを使います。指定がなければ、操作ツールで開いているブラウザとタブを確認し、Tripoへログイン済みのブラウザや、アバターキットを表示中のブラウザを優先します。
2. 対象ページのタブが既にあれば、そのタブを使います。アバターキットは依頼に示されたURL・ポートを確認し、同じアプリのタブを追加したり、操作のためだけに再読み込み・開き直しをしたりしません。
3. 対象ページのタブがなければ、既存ブラウザの同じウィンドウ・プロファイルにタブを追加します。ユーザーが別の作業をしているタブの内容は置き換えません。
4. ブラウザが開いていないことを確認できた場合だけ、通常のデスクトップブラウザを新しく起動します。ユーザー指定がなければChrome系ブラウザを使います。制作のために別の自動操作用プロファイルやヘッドレスブラウザを作りません。
5. ブラウザの一覧取得や接続が失敗した場合は、「ブラウザが開いていない」と判断しません。既存ブラウザへの接続や対象タブの指定を案内してください。接続できないことを理由に、Codex内ブラウザや別のブラウザセッションへ自動で切り替えません。

Codexで既存のブラウザやログイン状態を使う場合は、利用可能なブラウザ接続を使います。Codex内ブラウザは通常のブラウザと別の状態を持つため、既存ブラウザの代わりとして開きません。接続の設定は[公式OpenAIドキュメント](https://learn.chatgpt.com/docs/chrome-extension)を参照してください。

## アバターキットの依頼を受けたとき

依頼文の `agent-session.mjs begin` を通常実行し、依頼を出したタブを開いたまま、最新状態の保存を待ちます。この開始コマンドのために別タブを開く必要はありません。完了通知によるアプリの自動再読込を使い、別の画面から依頼を作り直しません。

依頼後にユーザーがタブを再読み込み・開き直した場合や、依頼が失効した場合は、現在のタブで内容を確認して依頼文をコピーし直すよう案内します。古い依頼のまま制作を始めません。
